# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **断网登记与合并**：断网时登记样本、染色批次和多个观察视野，进入离线队列；网络恢复后合并到室内记录。同一玻片同一批次只保留一条记录，重复视野（倍数+结构相同）并入去重，已有内容不被后到内容覆盖
- **染色批次失效**：批次失效后，已确认观察转为待重新确认，未完成草稿暂停；批次恢复后草稿继续，已确认观察仍需人工重新确认
- **复核冲突保护**：两人同时提交复核只通过一份（基于修订号的乐观并发），后到者的草稿与依据保留在详情中，可按当前版本重新提交
- **合并异常恢复**：合并前自动快照；异常条目暂挂并记录原因，可修复后重试或一键回滚到合并前
- **版本兼容**：旧版 v1 数据自动迁移到当前版本，原始数据保留存档；看板、详情、导出共用同一数据版本标识（schema 版本 + 全局修订号）

## 目录结构

- `src/domain/types.ts` — 领域模型与常量
- `src/domain/migrate.ts` — 旧版数据迁移
- `src/domain/store.ts` — 版本化存储、合并引擎、批次失效、复核并发
- `src/App.tsx` — 看板 / 登记 / 合并中心 / 详情复核 / 导出
